# Frame Studio design

Designers compose presentation images at a desk in daylight, comparing screenshots and materials; a light, quiet workspace keeps color judgments reliable.

## Visual system
Product register. Restrained neutral interface, warm gray work area and muted forest-green accent for selected controls. The artwork canvas can carry full color independently. System sans typography; 12px metadata, 13px controls, 15px section titles, 20px wordmark. Open sections separated by thin rules, 8px controls, a spacious central canvas. Consistent Lucide outline icons. Motion only for hover and state transitions, respecting reduced motion. Keyboard-accessible native inputs and clearly visible focus outlines.

## Layout
60px header, 300px scrollable inspector, flexible canvas workspace, 34px status footer. Responsive inspector stacks below the preview on mobile. Primary action: export PNG. Core workflow: screenshot, style, composition, background, export.
