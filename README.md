# Frame Studio

浏览器里的 iPhone 17 Pro Max 样机工作台。React + TypeScript + Vite + Three.js，无后端。

## 启动

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5188
```

生产构建：`npm run build`。将 `dist/` 部署到任意静态托管服务。

## 使用

- 上传 PNG / JPG / WebP 截图，也可以拖入画布；图片完全在本地处理。
- 拖动手机进行三轴中的俯仰和水平旋转，侧栏调整画面倾斜、相机视角、模型大小。
- 摄影模式：PBR 金属机身、环境照明、玻璃反光、透视相机。
- 3D 使用透视相机，通过「表面材质」下拉菜单独立选择「阳极氧化铝」「抛光不锈钢」「Clay」「Glow」。Clay 为柔和哑光；Glow 保留更纯的机身颜色，减弱光照明暗和反射。支持自定义机身色。
- 2.5D 是正交、非金属的快捷设定：从原生材质切入时选择 Clay；已选 Glow 则保留。2.5D 下可切换 Clay / Glow，透视滑块和金属材质选项禁用；返回 3D 后保留当前材质。
- 支持纯色、双颜色渐变、上传图片背景，以及五种画布比例。纯色背景、渐变背景和机身色各有一个自定义槽，记录最后一次自定义选择；渐变同时保存两种颜色和方向。预设切换不会覆盖槽，点击方形色槽可恢复，刷新后仍保留。
- PNG 导出 1× / 2× / 3×，最长边分别为 1600 / 3200 / 4800 px，默认包含背景和阴影；勾选透明背景后仅导出样机。
- 数字输入、键盘方向键和原生范围控件可操作角度，拖动模型和数字输入均可连续跨越 ±180°；手动滑杆固定在 −180°～180°，累计角度超出范围时滑块停在端点。预览左上角的机型名称为下拉菜单，与侧栏机型选择同步。

- 按住 Shift 拖动可移动手机，或在画布下方切换“移动”；滚轮仍用于缩放。16 个构图预设支持横向滚动浏览，包括侧立、近景、远景、俯视、仰视、横放和背面等；每个预设同时设置角度、缩放、透视与居中位置，可直接添加为当前时间的关键帧。
- 预览根据工具栏与时间轴之间的实际剩余空间适配，在不同画布比例下保持完整可见，不覆盖周围控件。比例选择框含两侧图标的整块区域均可点击；位置标题右侧的重置按钮只清零位移。
- 悬浮阴影使用模型网格投射到透明承影面的柔和阴影，承影面随模型边界移动和缩放，旋转会改变投影轮廓。加宽柔化范围、降低浓度并淡出承影面边缘，保持轻盈的悬浮效果。「阴影距离」可调节机身与承影面的间距，默认拉远并自动保存。透视、正交、PNG 和动画导出共享同一套阴影；透明 PNG 不包含承影面。
- 机身反光与玻璃反光独立调节；不再叠加可切换的灵动岛模型。17 / 15 系列 Logo 单独调色，Air 使用原模型的 Logo 遮罩；均随机身色调整并保留明暗对比。
- UI 色调随背景配色变化；图片背景使用平均色。
- 截图纹理保留原图分辨率（受 GPU 和 8192 边长限制），开启最大各向异性过滤和高分屏渲染。

## 模型与素材

现在使用 **Taufiq K 的 iPhone 17 Pro Max 现成 GLB 模型**（CC BY 4.0），约 3 万三角面、2.1 MB。保留原始镜组、侧键、接口、接缝和机身网格；不再使用原先的程序化简化模型。

模型采用 Origami 公开署名的 glTF 转换版本。本项目更换屏幕 UV 和显示材质，校准金属、玻璃与镜头，统一模型坐标。完整来源和许可说明在 `public/models/ATTRIBUTION.md`，画布工具栏的信息按钮也可打开署名页。

另提供 polyman Studio 的独立 iPhone 15 Pro Max 模型（CC BY 4.0）和基于 17 Pro Max 网格的 17 Pro 尺寸适配版。后者并非独立精确模型。详见模型署名文件。

屏幕采用发光 OLED 内容加 MeshPhysicalMaterial 的介电反射，反光来自 PMREM 摄影棚环境，随观察角度变化。黑色边框为非金属低反射材质，不再叠加原来的固定渐变玻璃层。简约模式关闭屏幕反射。

- 原作者及模型：https://sketchfab.com/3d-models/iphone-17-pro-max-e7c5674931ae4b0ea1b4eaaabb159fdb
- 许可：https://creativecommons.org/licenses/by/4.0/
- GLB 分发来源：https://origami.ltd/models/product/iphone-17-pro-max.glb
- Three.js（MIT）：https://threejs.org/ 。复用 RoomEnvironment / PMREM 和原生几何、材质、相机。
- Lucide（ISC）：https://lucide.dev/
- 示例摄影：Unsplash https://images.unsplash.com/photo-1470770841072-f978cf4d019e （图片资源 photo-1470770841072-f978cf4d019e）。仅用于内置示例。
- 示例屏幕由 Canvas 绘制，为虚构旅行应用。

默认画布为 1:1；编辑状态自动保存在当前浏览器，刷新或重新打开后恢复上次内容，并保持暂停。上传图片最大 25 MB、6400 万像素。需要支持 WebGL 2 的现代浏览器。

## 剪贴板、Air 与动画

- 「屏幕内容」和「背景」分别提供粘贴按钮。也可以先选中对应的 `⌘V / Ctrl+V` 目标，再用快捷键粘贴剪贴板图片。数字或文本输入框中的粘贴仍是正常文字编辑。剪贴板读取被浏览器拒绝时会提示使用快捷键。
- 屏幕支持 MP4 / WebM（最大 250 MB，取决于浏览器解码能力），支持填满或完整显示。视频从时间轴 0 秒开始播放；超出素材时长后保持末帧，时间轴循环时从头播放。音轨不播放、不导出。
- iPhone Air 使用 rtql8d 的独立 OBJ（CC BY 4.0），归一化坐标并重新配置材质。原模型的屏幕贴图含灵动岛，因此在替换屏幕内容时添加独立屏幕表面与灵动岛。来源和修改说明见 `public/models/iphone-air/ATTRIBUTION.md` 和应用的模型署名页。
- 「阳极氧化铝 / 抛光不锈钢」是金属外观预设。金属度不随反光滑块降低，玻璃背板保持独立介电材质；条形灯箱提供明暗反射。预设用于创作，不表示每个机型的实际材料。
- 时间轴支持 1–60 秒、播放/暂停与循环。刻度每 0.5 秒显示，拖动定位、方向键微调及关键帧时间以 0.1 秒为单位，播放保持连续；空白处和区间条带均可拖动定位，长时间轴可横向滚动。空格控制播放/暂停，编辑输入框时保留正常输入。将播放头移到目标时间，调整旋转、位置、大小或透视，再点击「添加关键帧」。同一时间再次点击会更新该帧。可拖动菱形或修改帧时间，也可删除选中帧。
- 曲线作用于选中关键帧到下一帧的区间。提供线性、平滑进出、缓入、缓出和自定义三次贝塞尔控制点；首帧之前和末帧之后保持姿态。旋转角度保存累计值，可越过 ±180° 并连续旋转多圈；关键帧按累计角度插值，例如 0° → 720° 会完整转两圈。构图预设选择离当前累计角度最近的等价姿态，避免无意倒转整圈。
- PNG 导出当前时间位置的静态画面，支持原有透明背景。动画导出为浏览器支持的 WebM 或 MP4，最长边 1280 px、30 fps 录制目标，包含背景与阴影，无音轨。导出按实际时长运行，需要保持页面可见；实际帧率取决于设备性能。
- 设置、关键帧、时间轴位置与上传素材自动保存在当前浏览器。轻量设置使用 localStorage，图片和视频使用 IndexedDB；刷新、关闭再打开会恢复，并保持暂停。清除站点数据会删除这些内容，存储不可用或空间不足时会明确提示。
- 界面保留功能标签、控件与 Frame Studio 标题，移除宣传文案和页脚；动画导出位于图片导出右侧。

验证：`npm run build`；动画插值单元测试：`npm test`（Node.js 22.18+ 或 24+，使用原生 TypeScript 类型擦除）。

### 区间曲线与材质修正

- 曲线编辑器现在明确显示「区间起点 → 终点」。点击两个关键帧之间的条带选择区间；曲线以起始帧的出段参数保存，计算 `起点 + (终点 - 起点) × 缓动进度`。最后一帧没有后续区间，不提供出段曲线编辑。
- 曲线数字参数可清空重填，在回车或失焦后校验范围；空值和无效输入恢复原值，Esc 取消修改。每个参数旁有实时更新的小滑杆。
- 新增「弹性轻柔」「弹性回弹」，可以调阻尼和振荡次数。曲线允许进度超过 100%，但在区间结束时精确回到目标值；后续区间保留自己的曲线。自定义贝塞尔的 Y 控制点也允许越界。为了避免相机失效或模型翻转，透视角和模型大小保留有效范围保护。
- 「金属粗糙度」控制高光宽窄，「环境对比度」控制亮灯箱与暗面之间的差异。「机身反光」减弱高光时保留环境底色，避免金属被压成纯黑。金属预设会填入相应粗糙度，之后仍可手动调整。
- 17 系列取消缺少可靠切线/UV 时的各向异性反射，修复背部噪点和三角形高光接缝；保留原始几何、法线与细节，没有通过降低模型精度掩盖问题。
- 15 系列补齐边框和镜头圈的材质映射，移除这两类金属表面原有的黑色贴图调制。deco 底板与镜片、Logo 原本合并在一个调色板材质内，现按连通网格分组，底板使用机身色，Logo 使用带明暗差异的机身色，镜片保留原材质。

### 屏幕轮廓与侧面细节

- Air 屏幕从 OBJ 正面玻璃的实际边界生成，按统一距离内缩，四角不再使用手工估算的圆角矩形。屏幕图片、视频和 PNG 导出共享此几何轮廓。
- 15 Pro Max 的信号条带、侧面矩形部件及其透明盖板使用独立的非金属材质；移除原始黑色贴图调制，采用略有明暗差异的机身色。盖板保留透明混合与关闭深度写入，避免与底层重叠闪烁。
